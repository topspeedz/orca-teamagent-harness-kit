# Agent·팀 검토 질문 노트

각 Agent와 팀을 하나씩 살펴볼 때 사용할 질문을 누적한다. 향후 검토 스킬의 체크리스트 초안으로 사용한다.

- [ ] **1. Agent 양식** — 프로젝트의 Agent 양식을 따르는가? 각 항목에 이 Agent의 실제 업무를 수행하는 데 필요한 내용이 충분히 적혀 있는가?
- [ ] **2. 문서 책임** — 이 Agent의 작업 중 문서로 남길 만한 내용은 무엇인가? 지속적으로 갱신하는 live 문서 중 이 Agent가 맡기에 적절한 문서나 절이 있는가? 있다면 실제로 담당자로 지정되어 있는가?
- [ ] **3. 역할 중복과 통합** — 다른 Agent와 겹치는 업무는 무엇인가? 서로 다른 작업 방법을 스킬로 나누고 하나의 Agent가 맡으면 더 효율적인가?
- [ ] **4. 전문 워크플로우와 근거** — 이 Agent의 업무에 맞는 효율적인 작업 절차가 있는가? 충분한 조사를 거쳐 검증된 방법론·워크플로우·이론을 참고했는가? 그 근거가 실제 절차의 어느 단계에 반영되어 있는가?
- [ ] **5. 필수·금지 행동** — 반드시 해야 하는 일과 해서는 안 되는 일이 명확한가? 실제 작업 절차에서 필수 행동을 수행하고 금지 행동을 피하도록 설계되어 있는가?
- [ ] **6. 모델과 effort** — 지정된 모델과 effort가 이 Agent의 업무 난이도와 필요한 판단 수준에 적절한가?
- [ ] **7. 협업 관계** — 이 Agent가 누구와 언제 협의하고 어떤 결과를 인계하는지 명확한가? 정해진 협업 관계로 불필요한 대기나 중복 작업 없이 진행할 수 있는가?
- [ ] **8. 팀 배치와 경계** — 각 Agent는 업무에 맞는 팀에 배치되어 있는가? 함께 처리할 일과 팀을 나누어 처리할 일의 경계가 실제 협업 흐름에 맞는가?
- [ ] **9. 에이전트별 스킬 배분** — 각 에이전트에게 맡은 작업 단위에 필요한 스킬이 배정되어 있는가? 빠진 스킬이나 다른 에이전트와 불필요하게 겹치는 스킬이 있는가?
- [ ] **10. 지정 Agent 저장소 검토와 활용** — 우리가 지정한 Agent 저장소에서 이 역할과 관련된 사례를 충분히 검토했는가? 그중 어떤 방법론·전문 지식·파이프라인·워크플로우를 골랐으며, 이 Agent의 실제 업무에 어떻게 활용하고 있는가?
