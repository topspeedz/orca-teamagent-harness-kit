# Agent Toggle

아래 명령의 `<SKILL_DIR>`에는 지금 읽은 이 SKILL.md가 있는 디렉터리의 절대 경로를 넣는다.

현재 프로젝트 루트를 작업 디렉터리로 유지하고 다음 명령을 백그라운드로 실행한다. Windows에서는 숨김 창으로 실행한다.

`node "<SKILL_DIR>/server.mjs"`

표준 출력에 표시된 로컬 URL을 기본 브라우저로 열고 사용자에게 링크를 전달한다. 사용자가 관리를 마치면 이 서버 프로세스를 종료한다.

창고 루트는 `~/.claude/agents-hans`다. 이름이 `kit`으로 끝나는 직속 폴더마다 토글 하나를 표시한다.

- ON은 키트의 에이전트, 담당 스킬, 전용 자료를 프로젝트의 같은 위치에 설치한다. 참고자료는 `.claude/<끝의 -kit을 뺀 이름>/references/`를 사용한다. 게임 기획 키트는 `.claude/game-design/`의 템플릿과 공용 문서도 설치한다. 기존 파일과 겹치면 충돌 경로를 표시한다.
- Codex 정의는 에이전트별로 `.codex/agents/<이름>.toml`에 생성한다. 담당 스킬이 있으면 설치된 SKILL.md를 읽도록 지시한다.
- OFF는 `.claude/agent-toggle/`의 설치 기록으로 해당 키트가 만든 파일을 제거한다. 수정된 파일이 있으면 경로를 알리고 제거를 중단한다.
- 기존 평면 원본과 설치 기록도 처리한다. 평면 원본에서 Claude만 설치된 항목의 ON은 Codex 사본을 추가한다.

에이전트 창고는 `~/.claude/agents-hans`의 원본을 표시한다. 프로젝트 에이전트에서 토글로 설치한 사본은 색상과 ‘창고에서 복사’ 표기로 구분한다.

프로젝트 에이전트의 ON/OFF는 Claude Code와 Codex 정의별로 적용한다. OFF는 정의 파일 이름 끝에 `.agent-toggle-off`를 붙여 같은 폴더에 보관하고, ON은 원래 이름으로 복원한다. 스킬과 참고자료는 계속 사용할 수 있다.

화면 아래 에이전트 구조도는 프로젝트의 에이전트 명단(`docs/harness/agents.md`)과 Claude Code 역할 정의를 읽는다. `product-manager`는 창구 아래에, 나머지 명단 에이전트는 코디네이터 아래에 같은 층으로 그린다. 에이전트를 끄면 카드에 ‘배정 대기’가 표시되고 그 에이전트로 가는 배정선은 그리지 않는다. 문서 담당은 유지된다. 창고 키트에서 설치한 에이전트와 명단에 없는 에이전트는 같은 카드로 아래에 따로 보인다. 옛 명단(`team-org.md`)만 있는 프로젝트에서는 구조도 대신 setup을 다시 돌려 옮기라는 안내 한 줄이 보인다. 역할 카드나 담당자 태그를 누르면 상세 설명과 엔진별 원문·활성 상태를 확인할 수 있다. 열린 구조도는 1초마다 변경을 확인하며 같은 서버의 `/team-structure.html`에서도 볼 수 있다.

프로젝트에 plan-orchestrate와 coordinator 스킬이 있으면 에이전트 카드 위에 사용자·창구, DAG 계획서, 코디네이터와 에이전트 배정 경로를 그린다. ‘공통 기준 문서’에서 색인의 정본이나 설치 초안을 열 수 있다. ‘모델 선택 표’에서 저장하면 현재 프로젝트 표가 갱신된다. 설문을 연 뒤 표가 바뀌면 다시 열어 새 값을 확인한다. 서버는 프로젝트에 설치된 설문 자산과 내용이 일치하는 사용자 플러그인 캐시의 키트 편집기를 사용한다.

전체에 하나인 ‘업무 관계 보기’에서 실선은 코디네이터(PM은 창구)의 작업 배정·보고, 점선은 직접 협업·설정 전달이다. 카드 하단의 업무 태그는 에이전트별 색, 스킬명 태그는 짙은 갈색 바탕에 금색 ★ 표시를 붙인다. 오른쪽 아래 ◇는 모델, ⚡는 effort의 첫 글자다. 칩에 마우스를 올리면 첫 설정을, 역할 요약에서는 작업별 설정을 확인할 수 있다. 직접 협업 탭은 양쪽이 켜진 협의 상대와 목적, 한도를, 문서 담당 탭은 문서·범위별 담당 에이전트와 주요 검토자를 표시한다. 담당 에이전트가 꺼져 있으면 ‘담당 꺼짐’, 담당이 없으면 ‘담당 없음’이다.

자가 점검은 `node "<SKILL_DIR>/check.mjs"`로 실행한다. Python Playwright와 Chromium이 있는 환경에서 `python "<SKILL_DIR>/check-team-ui.py" --kit "<설치 키트 저장소 경로>"`로 임시 설치 프로젝트의 HTTP·화면·저장을 검사한다.
