# 함정 목록 (증상 → 원인 → 처방)

설계 중 해당 표면을 만질 때만 찾아 읽는다. 전부 실측 사례다.

## 설정·발견

| 증상 | 원인 | 처방 |
|---|---|---|
| 자동 요약 설정이 어느 날 사라졌다 | `settings.json`의 `autoCompactWindow` 키는 CLI가 설정을 다시 쓸 때 지워진다 | `env.CLAUDE_CODE_AUTO_COMPACT_WINDOW`로 지정 |
| 스킬이 트리거되지 않는다 | 목록에서 description이 잘려 트리거 문구가 안 보임(`skillListingMaxDescChars`) | 트리거 문구를 description 앞쪽에. 잘리는 길이는 버전마다 `/context`·스킬 목록으로 확인 |
| 세션 시작 주입물이 크다 | 메모리·플러그인 요약이 매 세션 통째로 주입 | 조회 횟수로 판정한다 — 30일 688세션에 주입됐는데 조회 4회면 끈다(검색 경로는 남긴다) |
| Codex가 뒤쪽 지침을 통째로 안 읽는다 | Codex는 root→cwd `AGENTS.md` 체인을 세션 시작에 eager 로드, 중첩 lazy 없음, 예산(32KiB) 초과분은 파일 단위로 탈락 | 공유 T0는 13KiB 안팎, 절차는 온디맨드 문서로 내리고 포인터만 |

## 훅·권한

| 증상 | 원인 | 처방 |
|---|---|---|
| `ask` 게이트가 그냥 통과된다 | bypass 모드에서는 `permissions.ask`가 적용되지 않는다(`deny`는 적용된다) | bypass 세션은 `permission_mode`를 보는 훅 deny([templates.md §4](templates.md)) |
| 무인 워커가 훅 확인 프롬프트에서 조용히 멈춘다(대기는 타임아웃만 반환) | bypass가 아닌 모드로 뜬 워커에서 ask·훅 확인이 프롬프트로 뜬다. 원인은 대개 명령 문자열 오탐(`rm`·`del`·삭제 파일 경로 나열) | 무인 워커는 bypass로 띄우고 ask에 의존하지 않는다. 지시문에 "삭제 문자열을 복합 명령에 섞지 말고 임시파일은 스크래치에". 긴 무응답은 트랜스크립트가 아니라 터미널 tail을 직접 본다(트랜스크립트는 마지막 도구 호출에서 멈춘 것처럼 보인다) |
| 게이트가 무해한 명령도 막는다 | 명령 문자열에 패턴이 포함(체이닝·인용) | 오탐은 fail-closed의 대가 — 문서화하고 판정을 명령 위치로 좁힌다 |
| 행동 교정 deny를 넣었더니 턴이 오히려 는다 | deny된 호출도 재독 1회, 사유가 다음 턴을 만듦. 모델이 grep→cat→sed로 변형을 돌거나 `command grep`·절대경로로 우회 | 대체가 명확한 명령만 deny, 세션당 상한, 나머지는 비차단 알림. 측정 분류기는 우회 형태까지 같은 원인으로 접는다 |
| 워커가 T0 규칙(조회 묶기 등)을 따르지 않는다 | 시작 주입물 수십 k 사이에 묻힘 | 워커 프리앰블 뒤에 UserPromptSubmit으로 주입한다(Orca 틀의 `worker-intake-context` 훅) |
| 다른 런타임에서 훅이 안 돈다 | 이벤트·matcher 체계가 다름(예: Agent 위임 계층 없음) | 억지로 옮기지 않는다. 같은 목적을 수행하는 다른 표면을 적고 "의도적 비변환"으로 기록 |

## Windows·인코딩

| 증상 | 원인 | 처방 |
|---|---|---|
| 한글 `.ps1`이 문법 오류 | BOM 없는 UTF-8을 ANSI로 읽음 | `.ps1`은 UTF-8 BOM |
| Python 스크립트가 출력 단계에서 `UnicodeEncodeError: cp949` | 콘솔 인코딩. 산출물은 이미 생성돼 성공·실패를 오판 | `PYTHONUTF8=1` / `$env:PYTHONUTF8='1'` |
| git이 텍스트 파일을 Bin으로 표시 | 파일 쓰기 도구의 NUL 바이트 혼입 | 커밋 전 NUL 스캔 |
| Bash 도구로 쓴 정규식이 깨진다 | 백슬래시 접힘 | 정규식 든 스크립트는 파일 쓰기 도구로 생성 |
| 이모지(U+1F916 등)를 잃은 파일이 "승인 문장과 정확히 일치 ✅"로 통과했다 | 완료 기준 비교를 명령에 다시 친 문자열로 했다 — 파이프에서 spec 쪽과 대상 쪽 양쪽에서 같은 글자가 빠져 비교가 참이 된다 | 비ASCII가 든 완료 기준은 spec 파일과 대상 파일을 Node로 읽은 값끼리(`includes`·`codePointAt`) 비교. 한글 인자도 파이프·stdin 대신 파일로 넘긴다 |

## 검색 오염

폐기됐지만 지울 수 없는 디렉터리(런타임 입력·대용량 생성물)는 `.rgignore`로 **검색에서만** 제외한다.
의도적으로 찾을 때는 `rg --no-ignore` — 이 한 줄을 router에 남긴다.
