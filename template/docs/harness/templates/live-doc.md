## 규칙

- 현재 상태만 담는다. 날짜가 붙은 경과, 대체된 옛 내용, 백로그 번호 나열을 넣지 않는다.
- 30KB를 넘으면 주제별로 나눈다.
- 역할 정의에 지정된 작성자가 해당 경로·절을 처음 작성하고 변경 근거를 대조해 갱신한다. PRD·SRS는 `product-manager`가 작성한다. 다른 사람이 변경을 발견하면 문서·절과 근거를 작성자에게 넘긴다. 미배정이면 코디네이터가 담당 지정을 요청한다. `doc-steward`는 색인을 관리하고 반영 결과와 연결을 확인한다.
- 결정 기록(`docs/07-decisions/`), phase 색인(`docs/08-implementation/wbs.md`), 변경 이력(`docs/12-changelog/`)은 추가만 하는 기록이라 날짜와 phase 이름을 둔다.
