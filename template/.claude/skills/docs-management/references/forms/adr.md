# 결정 기록(ADR) 양식

> 읽는 시점: `docs/07-decisions/`에 결정 기록을 쓸 때.

- 바탕 표준: MADR의 절 구성과 Nygard의 상태 값.
- 정본 위치: `docs/07-decisions/NNNN-<제목>.md`. 결정 하나에 파일 하나다. `NNNN`은 네 자리 번호, 제목은 소문자와 하이픈으로 쓴다(예: `0003-use-server-sessions.md`).
- 이 문서가 정본인 것: 결정의 이유, 검토한 대안, 결과.

## 채우는 법

- 이미 내려진 결정만 기록한다. 출처는 승인된 설계서, 계획서, 브리프의 사용자 결정이다. 출처 칸에 설계서 경로와 절, phase 이름을 적는다.
- 코드만 보고 추측한 결정은 쓰지 않는다. 출처 없이 바뀐 것은 불일치로 올린다.
- 맥락, 선택지, 이유는 출처에 있는 말을 옮긴다. 출처에 없는 절은 "출처에 없음"이라고 쓴다. 지어내지 않는다.
- 추가만 하는 기록이다. 상태가 `승인됨`인 ADR의 본문은 고치지 않는다.
- 결정이 바뀌면 새 ADR을 쓴다. 옛 ADR은 상태만 `대체됨 (ADR-NNNN)`으로 바꾼다.
- 상태 값: `제안됨`(아직 승인 전), `승인됨`, `폐기됨`(더는 따르지 않고 대체도 없다), `대체됨`.
- 이 문서는 머리 네 줄 대신 아래 문서 구조의 머리 표를 쓴다.
- 쓴 뒤 아키텍처 문서 9절의 표에 번호와 제목 한 줄을 더한다. 아키텍처 문서가 아직 없으면 건너뛴다. 그 문서를 처음 쓸 때 9절에 ADR을 모두 나열한다.
