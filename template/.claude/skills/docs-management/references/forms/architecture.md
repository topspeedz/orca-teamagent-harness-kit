# 아키텍처 문서 양식

> 읽는 시점: `docs/04-architecture/architecture.md`를 처음 쓰거나 고칠 때.

- 바탕 표준: arc42의 열두 절.
- 정본 위치: `docs/04-architecture/architecture.md`. 30KB를 넘으면 절 단위로 나눈다(예: `05-building-blocks.md`).
- 이 문서가 정본인 것: 구조, 배치, 횡단 개념, 위험과 기술 부채. 결정의 이유는 ADR이, 품질 요구사항의 문장은 SRS가 갖는다.

## 채우는 법

- 열두 절의 제목과 순서를 그대로 둔다. 쓸 내용이 없는 절은 지우지 않고 "정해지지 않음"이나 "해당 없음"이라고 쓴다.
- 코드에서 확인한 구조만 적는다. 구성 요소마다 코드 경로를 붙인다.
- 9절에는 결정의 내용을 다시 쓰지 않는다. ADR 번호와 제목만 나열한다.
- 10절에는 요구사항 문장을 다시 쓰지 않는다. `NFR` ID를 가리킨다.
- 그림은 글로 그릴 수 있는 것만 넣는다(Mermaid 코드 블록 또는 표). 그림 파일이 저장소에 있으면 경로를 적는다.
- 모듈과 파일의 길잡이는 코드 지도(`docs/CODEBASE_MAP.md`)가 갖는다. 5절은 책임과 관계를 적고, 파일 목록은 옮기지 않는다.
