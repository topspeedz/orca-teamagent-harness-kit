# 예상시간 워터폴

사용자가 승인한 워터폴 형식을 재사용한다. 별도 설치나 CDN 없이 Node.js로 독립 HTML을 만든다. DAG 스윔레인은 시간 순서, 이 워터폴은 **소요시간에 비례하는 일정**을 보여 준다.

시각 기준은 [예제 HTML](assets/reference.html), CSS 정본은 [style.css](assets/style.css)다. 렌더러 변경 시 `node <skill-dir>/scripts/check.mjs`를 실행하고 example.json을 다시 렌더하여 reference.html을 갱신한다.

## 만들기

1. 현재 계획·DAG·작업 장부에서 ID, 의존성, 담당, 상태를 읽는다. 기억으로 완료 상태를 채우지 않는다.
2. [입력 계약](references/input.md)에 맞는 JSON을 산출물 폴더에 작성한다. [예제](examples/example.json)를 참고한다. 각 작업에 low/likely/high 분 단위 추정과 근거를 쓴다. 기존 계산기가 있으면 결과를 변환해 사용한다.
3. 각 시나리오의 시작·종료를 계산할 때 의존성과 실제 워커 수·역할별 동시 실행 제한을 지킨다. QA는 같은 빌드에서 증거가 준비된 영역부터 병렬 검증하되 최종 수락은 모든 검증 뒤에 둔다. 계획 변경이나 추가 워커 기동은 이 스킬의 권한이 아니다.
4. `node <skill-dir>/scripts/render.mjs <input.json> <output.html>` 실행. 같은 작업의 갱신은 같은 파일을 갱신한다.
5. 브라우저에서 탭 전환·가로 스크롤·작업 강조·한글·테마를 확인한다. 파일 링크를 제공하고 사용자가 띄워 달라면 실제 브라우저로 연다. 공개 게시를 요청받지 않았다면 로컬 파일로 전달한다.

## 유지할 형식

- 위쪽: 제목, 추정 기준일, 현재 상태, 자원 제한/추정 전제, 시나리오 요약표.
- 본문: low / likely / high 버튼, 왼쪽 고정 작업명 열 + 가로 스크롤 SVG. 1분=1.3px, 행=26px, 작업명 열=300px, 1시간 주 눈금·30분 보조 눈금. 전체를 화면 폭에 축소하지 않는다.
- 막대는 시나리오별 기간, 회색 수염은 같은 시작점의 low~high 범위. 색상은 기획/개발/검증/조정/하네스, 완료는 녹색. 승인 대기는 빨간 점선 상자로 표시한다.
- 행 호버 및 키보드 포커스 시 해당 작업·직접 선행·직접 후행 강조. 하단 상세표에 ID/백로그/역할/의존성/상태/추정/근거 표시. 라이트·다크 테마 지원.
- 실제 경과, 작업자 시간의 합, 병렬 작업 경과를 혼동하지 않는다. 추정은 완료 시각 보장이 아니다. 승인 대기 W, 준비 P, 감독 L 등 미정 시간은 0분으로 확정하지 말고 별도 명시한다.
- 현재 위치의 시간 근거가 없으면 상태 문구만 표시한다. 마지막 완료 작업의 예상 종료시각을 실제 현재시각으로 쓰지 않는다.
- 비교 요청 시 같은 범위·동일 자원 가정으로 전/후를 계산하고 차이를 설명한다. 인원을 늘린 비교는 별도 가정으로 표시한다.

렌더러는 제공된 일정을 검증·표현하며 자동 최적화하지 않는다. 잘못된 의존성, 순환, 기간, 자원 초과는 고친 뒤 출력한다. 사용자 작업명·범위·승인 상태를 시각화를 위해 변경하지 않는다.
